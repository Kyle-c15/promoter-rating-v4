# Portrait Service Feedback H5

This package contains only the portrait Service Feedback prototype. index.html is the GitHub Pages homepage.

## Deploy

1. Create a new empty GitHub repository.
2. Upload every file and folder inside this package to the repository root. Do not upload the ZIP file as the site source.
3. In Settings, open Pages and set Source to GitHub Actions.
4. Push to the main branch. GitHub Pages publishes the site automatically.

## Local Preview

Open index.html from a static web server. The H5 starts on the Pending feedback list.
